# docs/ — operational history and superseded write-ups

Nothing in this folder is a live source of numbers. Every figure the project
stands behind is regenerated by `claims.py` into `results/claims.json` and
quoted from there by [REPORT.md](../REPORT.md), [BENCHMARKS.md](../BENCHMARKS.md)
and the paper. What is kept here is the trail: what was asked of the second
machine, what came back, what was found to be wrong, and one document whose
claims were later retracted. Each file opens with a status line saying when it
was written and where its content now lives.

**How the GPU batteries were run.** Feature extraction needs a GPU, so it ran
on a second machine (one RTX 3070), and so did the CPU analysis chains of
batteries 1 and 4. That machine was driven by a separate AI assistant session
(Claude, through Claude Code), which worked only from the instruction
documents below and wrote its reports back. The instructions therefore read as
complete runbooks: protocol, seed rules, what to run, what to send back, and
what counts as a failure.

every later battery inherited.
