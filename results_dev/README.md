# results_dev/ — development-seed records

The per-seed records from development seeds 0–1, on which every threshold and
configuration was tuned before the evaluation seeds (2–4) were first run. The
development-seed sections of [REPORT.md](../REPORT.md) — everything between the
rigor pass and "Final scoreboard vs published results" — quote them, and
`claims.json` here is the claims file as it stood at that point.

`claims.py` reads one family from this folder (the per-class apoptosis
certificates, which were developed here); every other reported number comes
from [`../results/`](../results/README.md). These files are not regenerated:
they are the record of what the development runs showed.
